# Approved Project-Contract Retrieval Corpus v1

This frozen corpus contains short, verbatim excerpts from the user-approved
product contracts in this workspace. It contains no personal-vault data,
donor-repository source, live CAM state, credentials, or web content.

The manifest records the source paths and SHA-256 digests observed before this
corpus was evaluated. It is a narrow real-project-policy corpus, not evidence
of broad personal-memory, real-repository, model-answer-faithfulness, or
multimodal retrieval quality. The existing synthetic mixed-modality v2 corpus
remains the regression contract for those lanes.

Do not alter the manifest or its labels after evaluation. Create a new
versioned corpus for any change.
