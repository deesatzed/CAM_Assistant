# Direction general-user protocol (Gate D6)

**Status:** Protocol ready — agents cannot satisfy this gate.  
**Companion:** Barebones Gate 7 protocol in `barebones-general-user-protocol.md`.

## Purpose

Prove a non-developer can use Pattern A Direction without Terminal, jargon, or
specialist workspaces.

## Environment

- Temporary Standard macOS account (or disposable profile root).
- Packaged CAM Assistant with production experience.
- Synthetic personal content only (no real third-party secrets).
- Optional: Local AI running for Talk library path; offline Talk coach still required.

## Steps

1. Launch app. Confirm only Home, Library, Settings.
2. On Home, see **Direction** above Save/Find.
3. Add a person (real name) and one promise.
4. Restart app. Confirm person and promise still show.
5. Save clipboard content; Find it in Library (N4 still works).
6. Open **Talk** without Local AI: see offline coach; no invented partner answer.
7. (Optional) With Local AI Ready: Talk about Library content; check sources or honest “not enough.”
8. Backup and restore (if comfortable): Direction still present.

## Pass criteria

- Completes steps without assistance on jargon.
- Can explain content stays on this Mac.
- Direction did not require Meaning Preview or developer mode.
