# Meaning Preview v1 Human Pilot Protocol

**Status:** Draft — approval and participants required  
**Software prerequisite:** ADD2CAM-50 packaged journey pass at `65e6e3d`  
**Human gate:** ADD2CAM-60 (agents must not execute this protocol as lived evidence)

## Purpose

Assess whether optional Meaning Preview is useful and trustworthy for ordinary local work without becoming notification spam, judgment theater, or an automatic agent.

## Participants

- Consented adults only  
- No personal/production vaults unless the participant explicitly opts in with a disposable copy  
- No clinical, legal, or financial decision reliance  

## Session outline (draft)

1. Install/launch the exact packaged build under test  
2. Confirm Meaning Preview is off by default  
3. Enable from Settings — verify no data access yet  
4. Open Meaning Preview workspace — Grant only if willing  
5. Select one local source (or accept sole-source selection) and Request  
6. Review card or silence; Inspect; Now / Later / Release; optional Helpful / Not helpful  
7. Disable and confirm ordinary Assistant unchanged  
8. Debrief: usefulness, trust, friction, whether they would keep it enabled  

## Prohibited

- Fabricated participants or synthetic-to-human evidence substitution  
- Requiring Grant to use the rest of CAM Assistant  
- Cloud / CAM mining / Mac mutation as part of this pilot  

## Approval required before recruiting

- Human owner approves this draft  
- Consent language finalized  
- Build identity and retention rules for notes fixed
